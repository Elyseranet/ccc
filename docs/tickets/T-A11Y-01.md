# T-A11Y-01 — Accessibilité : corrections de l'audit RGAA 4.1 / WCAG 2.1 AA du 2026-11-05

- **Statut** : À faire. Ouvert le 2026-11-05 par le chef de projet.
- **Source** : `docs/audits/2026-11-05-accessibilite.md`, sur develop ff85c00. L'audit est **statique** : aucune mesure axe, navigateur ni lecteur d'écran ; les contrastes sont calculés à la main et les numéros RGAA cités de mémoire. Chaque point doit donc être **confirmé par une mesure** avant d'être corrigé. Un point que la mesure invalide est consigné ici avec cette mesure.
