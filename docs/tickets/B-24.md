## Contrat

- `POST /matchs/{id}/correction` sur un match de **poule** : `409 TIEBREAK_ENGAGED` (nouveau) s'il existe un match `TIEBREAK` dans l'édition, quel que soit son statut : départage de la même poule, ou départage de frontière (`pool_id` nul, bloque toutes les poules). Contrôle avant `NEXT_ROUND_ENGAGED`. Phase finale non concernée.
- `DELETE /editions/{id}/departages/{matchId}` (administrateur) : `204`. 404 (pas un départage de l'édition), `409 TIEBREAK_PLAYED` (nouveau : saisi, validé, ou un côté a un score), `409 EDITION_CLOSED`. Transaction, édition verrouillée, côtés supprimés par cascade. Journal `tiebreak_deleted`.
- Pas de migration (`fk_match_sides_match` est déjà `ON DELETE CASCADE`).

## Critères d'acceptation

- [ ] Correction refusée pour un départage de poule (même poule) et de frontière ; acceptée dans une autre poule.
- [ ] Suppression d'un départage non joué : 204, l'égalité réapparaît, le départage peut être recréé ; refus d'un départage joué ; 401, 403, 404, 409 `EDITION_CLOSED`.
