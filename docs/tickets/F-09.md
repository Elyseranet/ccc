## Contrat B-10 (`docs/api/admin-editions.md`, branche B-10)

- **Ajout** : `POST /api/v1/editions/{id}/participants`, avec `{ competitorId }` pour un profil existant ou `{ newCompetitor: INewCompetitor }` pour un nouveau.
  - `INewCompetitor` = `{ email, firstName, lastName, nickname?, phone? }`, **sans avatar**.
  - Le type de requête d'ajout est celui livré par B-10 dans `src/types/` ou `src/interfaces/` (FA-02 abandonnée, ARCH-4). Il n'est pas dans develop au 2026-10-22 : le reprendre tel que B-10 le livre, sans le redéclarer.
  - Réponse 201 `IAddParticipantResult` : `IEditionParticipant` + `invitationSent: boolean | null`.
- **Message de confirmation selon `invitationSent`** :
  - `true` : « Invitation envoyée » ;
  - `null` : profil existant rattaché, aucune invitation ;
  - `false` : participant créé, mais invitation non envoyée. C'est le cas tant que B-09 n'est pas branché. On l'affiche honnêtement, jamais comme un envoi réussi.
- **Photo** : second appel, `PUT /competiteurs/{id}/avatar` (B-16). Voir la section Avatar.
- **Retrait** : `DELETE /api/v1/editions/{id}/participants/{participationId}` → 204.
  - **Décision Q1** : le retrait est autorisé tant que le tirage des poules est **en brouillon**, et refusé (409 `REGISTRATION_CLOSED`) une fois le tirage **validé**.
  - **Décision Q2** : l'ajout est autorisé jusqu'à la validation du tirage.
  - L'écran se fie à la réponse du serveur. Le bouton n'est masqué que d'après un état connu de l'API : tirage validé, ou édition au-delà de l'inscription.
- **Erreurs à traduire**, une clé i18n par code :
  - 409 `PARTICIPANT_ALREADY_REGISTERED` ;
  - 409 `REGISTRATION_CLOSED` ;
  - 409 `EDITION_CLOSED` ;
  - 409 `EMAIL_ALREADY_USED` (avec proposition de rattacher le profil existant, comme dans la maquette) ;
  - 404 `COMPETITOR_NOT_FOUND` ;
  - 400 `VALIDATION_FAILED`.
- La première inscription fait passer l'édition de `CREATED` à `REGISTRATION`. Après l'ajout, on recharge l'état de l'édition (le contexte admin).

- **Inscrits** : `origam-data-table` `items-per-page="8"` `density="compact"`. États du compte : Invité, Actif, Invitation expirée (→ Renvoyer). Retrait possible seulement avant le tirage.
