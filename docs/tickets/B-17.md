## Périmètre

1. **G2 — parcours par édition sur la fiche joueur** (F-04, spec P5.4 et R-5). `ICompetitorParticipation` gagne :
   - `poolRank` (numéro de la poule, distinct de la place dans la poule) ;
   - `poolPlace` (la place dans la poule, l'actuel `poolRank` de la participation) ;
   - `wins`, `losses` et `unknownResults` de l'édition (matchs `REGULAR`, R-5).

   Renommer l'actuel `ICompetitorParticipation.poolRank` est une **rupture** du contrat déjà consommé. Elle est acceptable parce que F-04 n'est pas encore livré, mais elle doit être confirmée avec le front-lead avant le code. Variante sans rupture : garder `poolRank` pour la place, et ajouter `poolNumber`. **C'est la variante retenue par défaut.**
   Calcul : réutiliser `computeWinLoss` de B-03 sur les matchs de l'édition (clé `COMPETITOR`), sans nouveau calcul.
2. **G3 — titres de l'adversaire dans le face-à-face** (F-04). `IHeadToHeadSummary.opponent` devient `ICompetitorWithTitles` (`ICompetitorPublic` + `titles`, nouvelle interface dans `competitor.interface.ts`, réutilisée au point 3). Les titres se comptent avec `countTitles` de B-03, sur les éditions CLOSED (A8), comme la liste des compétiteurs.
3. **G4 — finale dans la chronologie** (F-02). `IEditionSummary` gagne `final: IEditionFinal | null`, avec `IEditionFinal = { runnerUp: ICompetitorPublic, score: { champion: number, runnerUp: number } | null }`.
   - `runnerUp` : la participation `FINALIST` de l'édition.
   - `score` : les scores validés du match de finale (`ROUND_KIND.FINAL`, `VALIDATED`) ; `null` si la finale est d'archive sans score (`RESULT_UNKNOWN`).
   - `final` vaut `null` tant que l'édition n'a pas de finaliste.
   - Le calcul est fait en une passe pour toutes les éditions de `GET /editions`, sans une requête par édition, et c'est vérifié par un test sur le nombre de requêtes ou par la structure du service.
4. **G6 — enums de tri dans le contrat.** `SORT_ORDER` et `COMPETITOR_SORT` passent de `server/enums/competitor-sort.enum.ts` à `shared/enums/competitor-sort.enum.ts` (FA-02). On met à jour les imports serveur, sans changer aucune valeur.
5. **G7 — contrat anticipé (interfaces et enums uniquement, aucune route)**, pour que le front avance sur fixtures :
   - B-11 :
     - `ICreatePoolDrawRequest` `{ poolCount, seedCount, seeds: string[] }` ;
     - `IUpdateDrawAssignmentsRequest` `{ assignments: { participationId, poolRank, drawnOrder }[] }` ;
     - `IAdminDraw` (`IDraw` + `createdBy: IAdminActor | null` + `validatedBy: IAdminActor | null`) ;
     - `ISeedProposal` `{ seeds: { participationId, competitor, rank }[], unresolvedTies: string[][] }`.
