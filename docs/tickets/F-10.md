# F-10 — Compte : connexion, première connexion, Mon profil

- **Statut** : **Bloqué (design)**. Pas de maquette Happy Hour (FA-01b). Le chemin de « Mon profil » attend FA-06.
- **Vague** : 1 (parallélisable dès que la maquette existe)
- **Worktree** : `../CCC-F-10`, branche `feature/F-10-account`
- **Dépendances** : F-00, qui fournit le store d'authentification, le middleware et le lien « Connexion » du pied de page.
- **Référence** : wireframe `docs/design/ux/wireframes/compte.html`. Il n'existe **pas** de maquette HH.
- **Régime d'animation** : CSS uniquement.

## Périmètre (fichiers)

- `app/pages/connexion.vue`, `app/pages/invitation/[jeton].vue`, et la page « Mon profil » (FA-06)
- `app/components/account/` : `LoginForm.vue`, `InvitationForm.vue`, `ProfileForm.vue`
- `app/composables/useLogin.ts`, `useInvitation.ts`, `useProfile.ts`. Ils s'appuient sur `auth.store.ts` de F-00, qu'on ne duplique pas.
- Clés i18n `account.*`

## Composants Origam

- `origam-form`, `origam-text-field` (`type="email"`), `origam-password-field`, `origam-file-field` (avatar), `origam-btn`, `origam-alert`.
- Un `label` visible par champ ; les erreurs sont liées par `aria-describedby`.

## Endpoints

- `POST /auth/login`, `POST /auth/logout`
- `GET /auth/invitation/{jeton}` et `POST /auth/invitation/{jeton}`. **410** si le lien est expiré ou déjà consommé.
- `GET /moi`, `PATCH /moi`
- **Je ne sais pas** quels champs un participant peut modifier (Spec fonctionnelle, Questions ouvertes ; Q13 de `parcours.md`). Le formulaire ne peut pas être figé sans cette réponse.
- Le choix entre session et jeton est ouvert dans la Spec API, et revient à `backend-lead` ; le front s'adapte.

## Critères d'acceptation

- [ ] Iso-visuel avec la maquette HH à venir, à 1440 et 390 px.
- [ ] Une fois connecté, l'en-tête affiche « Mon profil » (participant) ou « Espace organisateur » (administrateur) (E-d) ; à la déconnexion, retour à l'état public.
- [ ] États : lien expiré ou consommé (410), mot de passe refusé, identifiants invalides, profil incomplet.
- [ ] Aucun secret ni jeton dans `localStorage`. Le mode de stockage est aligné sur le choix session ou jeton de `backend-lead`.
- [ ] `npm run test:run` et `npm run test:a11y` verts ; revue `/security-review` sur la branche.
- [ ] Definition of Done commune (`BOARD.md`).
