# F-44 — Qualification : supprimer un départage non joué

- **Statut** : Ouvert (2026-11-14). Décision utilisateur CORRECTION-TIEBREAK (`decisions.md` @ 204ad978) : la correction d'un match de poule est refusée tant qu'un départage existe, et un départage non joué peut être supprimé pour permettre la correction.
- **Dépend de** : B-24 (backend-lead, dev-b13). Contrat : `DELETE /api/v1/editions/{id}/departages/{matchId}` (administrateur), réponse 204. Refus : 404 si ce n'est pas un départage de l'édition ; 409 `TIEBREAK_PLAYED` si un score est enregistré ou validé ; 409 `EDITION_CLOSED`. Après la suppression, l'état de qualification remontre l'égalité ; rien n'est stocké.
- **À faire** :
  1. ui-plus : maquette de l'action « Supprimer le départage » sur la carte d'égalité de l'écran de qualification (F-24, `admin-qualification.html`), avec sa confirmation (DIALOG-THEME, DIALOG-ALIGN), l'état inactif d'un départage joué avec sa raison, et les erreurs ;
  2. front : action, appel au service, rechargement de l'état de qualification, tests de composant et e2e.
- **Critères** :
  - zones visuelles sous 1 % contre la maquette (dialogue selon DIALOG-ZONES) ;
  - a11y verte ;
  - typecheck, `test:run` et Playwright verts.
