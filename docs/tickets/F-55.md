# F-55 — « Phase finale » ouvre l'étape en cours, pas toujours la qualification

- **Statut** : Ouvert (2026-11-16).
- **Constat (utilisateur)** : en phase finale (édition `PLAYOFFS`, quarts joués), l'entrée « Phase finale » du tiroir ouvre la page Qualification. `src/pages/admin/phase-finale/index.vue` redirige toujours vers `ROUTES.ADMIN_FINAL_PHASE_QUALIFICATION`.

Réutiliser la logique d'étape existante (tableau de bord `admin-dashboard.util.ts`, `ADMIN_DASHBOARD_STEPS`) plutôt que d'en écrire une seconde.
