- **Confirmation de validation** : `origam-dialog` `persistent` `max-width="560"` `scrim`. Le texte dit que la validation est **non annulable** ; le focus initial est sur « Annuler ».

- **Transverses** : `PlayerLink`, `AsyncState`.

## Endpoints (B-11)

- `GET /api/v1/editions/{id}/tetes-de-serie?poules={n}` : propose les têtes de série et signale les égalités non tranchées (RG9, RG10).
- `POST /api/v1/editions/{id}/tirages/poules` : crée le tirage en brouillon (`{ poolCount, seedCount, seeds }`).
- `PUT /api/v1/tirages/{id}/affectations` : brouillon idempotent ; le contenu est remplacé à chaque appel.
- `GET /api/v1/admin/editions/{id}/tirages` : brouillons compris, avec auteur.
- `POST /api/v1/tirages/{id}/validation` : fige le tirage, génère le round-robin (RG15) et passe l'édition à `POOLS_DRAWN`.
- Erreurs : 409 (têtes de série ≠ nombre de poules, tirage déjà validé, participants non arrêtés), 403, et réseau.
