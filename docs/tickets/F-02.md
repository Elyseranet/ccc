## Composants Origam

- **Onglets** : `origam-tabs` `variant="pills"` `rounded="full"` `color="primary"`, avec `origam-tab-panels` / `origam-tab-panel`. `ITabProps` n'étend pas `ILinkProps`, donc l'onglet actif se synchronise à la main sur `?onglet=` (état partageable, `parcours.md`).
- **Classements** : `origam-data-table` `headers` `items` `density="compact"` `hover` `sort-by` `caption`. Les titres sont rendus en astérisques (RG6) dans le slot de cellule.
- **Évolution** : `origam-chart` `type="line"` `series` `categories` `show-legend` `show-grid` `show-tooltip` `:animated="false"`, avec un tableau équivalent sous « Voir en tableau ».
- **Chronologie** : `origam-card` `rounded="lg"` `border` `elevation="none"`, une par édition. 2012 compte deux éditions.
- **Transverses** : `PageHero`, `GoldenRules`, `BubblesBackdrop`, `PlayerLink`, `AsyncState`.

## Endpoints

- `GET /classements/acp`, `GET /classements/all-time`, `GET /classements/evolution` (RG4, RG8)
- `GET /editions` : `IEditionSummary.champion` pour la chronologie (C2).
- `GET /classements/evolution?type=` sans `competiteur` → `IRankingEvolutionSeries[]` pour le tableau de tous les joueurs (C5).
