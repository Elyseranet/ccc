# F-43 — Bouton outlined dans une alerte d'erreur : contraste 2,27:1

- **Statut** : Ouvert (2026-11-14). Défaut relevé par ui-plus pendant la maquette de F-18, dans un motif déjà existant.
- **Constat** (ui-plus, maquettes) : le bouton outlined placé dans une alerte d'erreur (« Recharger », « Vérifier l'état »…) a un texte crème sur `danger.bg`, avec un contraste de 2,27:1, sous le minimum de 4,5:1 (WCAG 1.4.3). Le motif apparaît dans les maquettes de qualification, de tirage de tour et de clôture. Je ne sais pas si l'app reproduit exactement ce contraste : à mesurer écran par écran.
- **Piste** (ui-plus) : dans une alerte, le bouton prend la couleur de texte de l'alerte (`danger.fg`, environ 7:1), à régler par les props Origam ou le thème (PROPS-FIRST), sans valeur en dur.
- **À faire** :
  1. ui-plus corrige le motif dans les maquettes concernées ;
  2. un dev mesure l'app (getComputedStyle et ratio de contraste) sur chaque écran qui a une alerte avec bouton, puis corrige.
- **Critères** :
  - contraste d'au moins 4,5:1 mesuré sur chaque occurrence, aux deux largeurs ;
  - les zones visuelles concernées restent sous 1 % contre les maquettes corrigées ;
  - a11y (axe) vert ;
  - typecheck, `test:run` et Playwright verts.
