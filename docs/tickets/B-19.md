- **Dépend de** : merge de la vague 3a. `IEditionFinal` arrive avec B-17 (G4) et n'est pas encore dans `develop`.
- **Constat**, sur `feature/integration-wave3a` @ `77fda80` :
  - `IEditionChampion` porte `titlesToDate` (`src/interfaces/edition.interface.ts`), calculé dans `src/services/edition.service.ts:182-188`. C'est le nombre de titres du champion jusqu'à cette édition comprise, par `chronologicalRank` ;

## Contrat proposé (ajout, sans rupture)

```ts
export interface IEditionFinal {
  runnerUp: ICompetitorPublic
  /** Titres du finaliste remportés jusqu'à cette édition comprise (il ne l'a pas gagnée), même calcul que `champion.titlesToDate`. */
  runnerUpTitlesToDate: number
  score: { champion: number, runnerUp: number } | null
}
```
