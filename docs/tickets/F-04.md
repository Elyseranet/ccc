## Composants Origam

- **Recherche** : `origam-form` `validate-on="submit"`, avec `role="search"`. Champ `origam-text-field` `type="search"` `variant="solo"` `rounded="full"` `clearable`, avec un `label` **visible** (le placeholder ne remplace pas le label).
- **Filtre d'édition** : `origam-select` `items` `variant="solo"`.
- **Annuaire** : `origam-data-table` `items-per-page="20"` `sort-by` `density="compact"`. Une région `role="status"` annonce le nombre de résultats.
- **En-tête de fiche** : `origam-card` `rounded="xl"` `border` `elevation="md"`, avec `origam-avatar`. **Jamais d'email ni de téléphone.**
- **Parcours** : `origam-data-table` `density="compact"`.
- **Adversaires** : `origam-list`. Le lien « Face-à-face avec X » est un `origam-btn` `variant="text"` vers `/joueurs/face-a-face?a=&b=`, avec un nom accessible complet.
- « Comparer avec… » mène à `/joueurs/face-a-face?a=<id>`.
- **Transverses** : `PageHero`, `PlayerLink`, `AsyncState`.

## Endpoints

- `GET /competiteurs?q=` : public depuis E-e. Champs publics seulement, avec limite de débit.
- `GET /competiteurs/{id}` : fiche.
- `GET /competiteurs/{id}/face-a-face` : adversaires fréquents (RG36).
- `GET /editions` : options du filtre.
- `GET /competiteurs?edition=` → `IPaginated<ICompetitorListItem>` (`editionsPlayed`, `matchesPlayed`, `wins`, `titles`, `firstEditionCode`) (C4). `matchesPlayed` inclut les matchs d'archive sans résultat, alors que `wins` ne compte que les validés : l'écart est voulu, et ne doit pas servir à calculer un ratio.
