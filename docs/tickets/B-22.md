# B-22 — `closedAt` exposé dans `IEditionDetail` (suite de B-14, demandé par F-26)

- **Statut** : **En revue** (livraison au `backend-lead`).
- **Origine** : F-26. La maquette validée affiche « Clôturée le 16/06 à 00:20 ».
- **Worktree** : `../CCC-B-22`, branche `feature/B-22-edition-closed-at`.

## Constat (vérifié dans le code)

- `closed_at` est écrit à la clôture (`closeEdition`, `src/services/edition.service.ts`) mais n'est lu nulle part : ni `IEditionDetail` ni `IEditionSummary` ne le portent.
- Dans `src/assets/seeds/archives.sql`, les **16 éditions d'archives sont `CLOSED` avec `closed_at` NULL**. Aucune date n'est inventée : elles renvoient `closedAt: null`.

## Contrat

- `IEditionDetail.closedAt: string | null` (ISO 8601), renseigné par `loadEditionDetail`, donc par `GET /editions/{id}` et par `POST /editions/{id}/cloture`. `null` tant que l'édition n'est pas close, et pour les archives.
- `IEditionSummary` ne change pas.
