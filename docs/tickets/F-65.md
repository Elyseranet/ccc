# F-65 — Bouton « Exporter (Excel) » sur la fiche d'édition admin

- **Statut** : Ouvert (2026-11-18). Dépend de B-30.
- **Comportement** : sur la fiche d'édition admin (et dans la liste des éditions si c'est naturel), bouton « Exporter (Excel) » qui télécharge `ccc-<code>.xlsx` via la route B-30 (`GET /api/v1/admin/editions/{id}/export.xlsx`). Lien de téléchargement natif (`<a download>` vers la route, la session suit) plutôt qu'un appel JS, si la garde d'architecture le permet ; état d'erreur si la route échoue. Disponible pour toutes les éditions, archives comprises.
- **Critères** : e2e (le téléchargement produit un fichier .xlsx non vide), a11y du bouton ; typecheck, `test:run`, `test:release` verts ; maquette admin-editions.html + mapping.md.
