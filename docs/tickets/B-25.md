# B-25 — Rouvrir les qualifications tant que le tirage du premier tour n'est pas validé

- **Statut** : Ouvert (2026-11-16). Mergé dans develop @ `279a681b` (branche `af4a1df8`), gates vertes sur develop (typecheck, `test:run` 1480 / 0, `test:release`), tests API qualification et tirage de tour 41/41. **Non fermé** : sur dev déployé (`279a681b`), `DELETE /api/v1/editions/x/qualification` sans session répond 404 `NOT_FOUND` « Resource not found » au lieu de 401 (le `POST` sur le même chemin répond 401). Cause en cours d'analyse.
- **Contrat livré** : `DELETE /api/v1/editions/{id}/qualification`, 200 `IQualificationStatus` (comme le GET admin), idempotent ; 409 `QUALIFICATION_LOCKED` (édition en `PLAYOFFS`), 409 `QUALIFICATION_NOT_DONE` (avant les poules), 409 `EDITION_CLOSED`. Effet : brouillons de tirage `ROUND` supprimés, participations en poule remises `IN_POOL`, édition à `POOLS_DRAWN`. Les départages déjà joués sont conservés.
- **Demande utilisateur (2026-11-16, capture)** : après « Arrêter la liste des qualifiés », aucun moyen de revenir en arrière en cas d'erreur.
- **Décision utilisateur (2026-11-16)** : la liste des qualifiés peut être rouverte **tant que le tirage du premier tour de phase finale (barrages, huitièmes ou quarts, selon l'édition) n'est pas validé définitivement**. Un brouillon de tirage de ce tour déjà commencé est effacé.
- **Contrat proposé** (à confirmer par le backend-lead, Spec API à mettre à jour) : `DELETE /api/v1/editions/{id}/qualification` (administrateur).
  - Édition `QUALIFIED` et aucun tirage de tour validé : la liste des qualifiés et le brouillon du premier tirage de tour sont supprimés, l'édition repasse au statut d'avant la qualification (celui que `finalizeQualification` quitte), réponse 200 avec l'état rendu.
  - Tirage de tour validé, ou édition dans un autre statut : 409 avec un code d'erreur dédié (`API_ERROR_CODE`).
  - Idempotent : rejouée sur une édition déjà rouverte, 200 sans effet (même règle que `POST …/qualification`).
  - Transaction unique, log `LOG_EVENT` dédié (édition, utilisateur, brouillon effacé oui/non).
- **Hors périmètre** : défaire un tirage déjà validé ou des matchs de phase finale.
- **Critères** : tests API (rouverture, brouillon effacé, 409 après validation, idempotence, 403 non-admin) ; typecheck, `test:run`, `test:release`, suites API concernées vertes ; Spec API mise à jour dans Obsidian.
