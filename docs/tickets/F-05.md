## Composants Origam (props vérifiées dans `interfaces/Select/select.interface.ts`)

- **Deux joueurs** : deux `origam-select` `autocomplete` `search` `items` `variant="solo"` `rounded="full"` `clearable`, dans un `fieldset` / `legend`.
- **Inverser** : `origam-btn` `icon` `variant="outlined"` `rounded="full"`, avec un `aria-label`.
- **Score des rencontres** : `origam-card` `rounded="xl"` `border` `elevation="md"`. La proportion s'affiche en barre **et** en texte « 2 – 2 », jamais par la seule couleur. Les départages sont exclus.
- **Bilans globaux** (RG37) : `origam-data-list` `density="compact"` `rounded="lg"`. C'est le **seul endroit public où le ratio apparaît** (FA-12).
- **Historique** (RG36) : `origam-data-table` `density="compact"`. Les rencontres sans score connu sont comptées à part, jamais comme des nuls.
- **Transverses** : `PageHero`, `PlayerLink`, `AsyncState`.

## Endpoints

- `GET /competiteurs?q=` pour l'autocomplétion.
- `GET /competiteurs/{id}/face-a-face?adversaire={id}` → `IHeadToHead`. La Spec API ne précise pas comment désigner le second joueur ; c'est B-05 qui fixe le paramètre `adversaire`.
