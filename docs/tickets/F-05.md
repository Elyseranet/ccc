# F-05 — Face-à-face

- **Statut** : **Bloqué (design)**. Pas de maquette Happy Hour (FA-01b).
- **Vague** : 1 (parallélisable dès que la maquette existe)
- **Worktree** : `../CCC-F-05`, branche `feature/F-05-head-to-head`
- **Dépendances** : F-00, et la maquette HH de `ui-designer`. Aucune dépendance de code envers F-04 : les liens entrants pointent vers une route créée par F-00.
- **Référence** : wireframe `docs/design/ux/wireframes/face-a-face.html`. Il n'existe **pas** de maquette `happy-hour/face-a-face.html`.
- **Régime d'animation** : écran dense, CSS uniquement.

## Périmètre (fichiers)

- `app/pages/joueurs/face-a-face.vue` (`?a=&b=`)
- `app/components/head-to-head/` : `HeadToHeadPicker.vue`, `HeadToHeadSummary.vue`, `HeadToHeadHistory.vue`
- `app/composables/useHeadToHeadComparison.ts` : synchronisation avec l'URL, inversion, cas d'erreur.
- Clés i18n `head_to_head.*`

## Composants Origam (props vérifiées dans `interfaces/Select/select.interface.ts`)

- **Deux joueurs** : deux `origam-select` avec `autocomplete` et `search`, dans un `fieldset` / `legend`.
- **Inverser** : `origam-btn`.
- **Bilan V–D** (RG36, RG37) : `origam-card`. Historique des rencontres : `origam-data-table`.
- **Transverses** : `PageHero`, `PlayerLink`, `AsyncState`.

## Endpoints

- `GET /competiteurs?q=` pour l'autocomplétion.
- `GET /competiteurs/{id}/face-a-face?adversaire={id}` → `IHeadToHead`. La Spec API ne précise pas comment désigner le second joueur ; c'est B-05 qui fixe le paramètre `adversaire`.

## Critères d'acceptation

- [ ] Iso-visuel avec la maquette HH à venir, à 1440 et 390 px.
- [ ] `?a=&b=` prérempli et partageable ; « Inverser » met l'URL à jour.
- [ ] États : même joueur deux fois (erreur liée au champ par `aria-describedby`), jamais affrontés, matchs sans score comptés à part, identifiant inconnu dans l'URL.
- [ ] `npm run test:run` et `npm run test:a11y` verts.
- [ ] Definition of Done commune (`BOARD.md`).
