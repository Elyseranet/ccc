## Composants Origam

- **Fil d'Ariane** : `origam-breadcrumb` `items` `density="compact"`.
- **Sélecteur d'édition** : `origam-select` `items` `variant="solo"` `rounded="full"`. Il change d'édition **en conservant l'onglet**. L'URL porte l'identifiant (`2012a`, `2012b`), pas l'année.
- **Onglets** : `origam-tabs` `variant="pills"` `rounded="full"` `color="primary"`, collants sous l'en-tête en bureau. Synchronisation sur `?onglet=` à la main, car les onglets ne sont pas des liens.
- **Déroulé** : `origam-stepper` `items` `orientation="vertical"` `:clickable="false"` `show-connectors`, 9 étapes, statuts `done`, `active`, `pending`.
- **Chiffres** : `origam-card` `rounded="xl"` `border` `elevation="md"`.
- **Participants** : `origam-list` dont chaque item porte `origam-avatar` (`text`, `rounded="full"`), `PlayerLink` et un `origam-chip` de résultat.
- **Tirages** : `origam-card`, avec un `origam-chip` `color="success"` pour le statut (RG9, RG11–RG13).
- **Poules** : `origam-table` `density="compact"` `hover` `caption` `border` `rounded="lg"`. Le Q des qualifiés est un `origam-chip` success. Le tri suit RG19. **RG18 (règle de qualification) reste ouverte côté spec** : le nombre de qualifiés par poule n'est pas codé en dur, il vient des données (fixture illustrative = maquette).
- **Bracket** : `origam-bracket` `rounds` `variant="single-elimination"` `show-scores` `show-round-titles` `:show-seed="false"` `:interactive="false"` `direction="horizontal"`.
  - **RG13** : aucun trait de liaison, car les affiches sont retirées à chaque tour. Aucune prop ne masque les connecteurs ; seul le slot `connector` existe (vérifié dans `OrigamBracket.vue`, l. 84 et 180). On essaie de le passer vide. Si un `<svg>` vide reste dans le DOM, ou si le rendu diverge de la maquette, voir FA-11.
  - Alternative en liste obligatoire ; région défilable focalisable, avec un nom accessible.
- **Matchs** : `origam-chip-group` `mandatory` `filter`, puis `origam-data-table` `items-per-page="16"` `density="compact"`, puis `origam-pagination` `total-visible="5"` `density="compact"`. Le numéro du match suit RG24 (`{édition}-{rang}`).
- **Transverses** : `PageHero`, `PlayerLink`, `AsyncState`.

## Endpoints

- `GET /editions` : sélecteur, et édition en cours pour `/editions`.
- `GET /editions/{id}` : vue complète.
- `GET /editions/{id}/participants`, `/tirages`, `/poules`, `/tours`, `/matchs`.
- La Spec API laisse ouvert le découpage de `GET /editions/{id}` en sous-ressources (« deux régimes de cache »). Le service suit ce que `backend-lead` livre.
