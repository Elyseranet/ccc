## Réalisation (dev-f13, branche `feature/F-25-round-draw`)
- Page `/admin/phase-finale/tirage` : états (qualification non faite, tour précédent incomplet, choix du tour, saisie affiche par affiche, tirage validé, terminé), vivier + « À placer », récapitulatif, validation avec dialogue de confirmation, dialogue « Changer le tour ». Enregistrement du brouillon à chaque affiche (PUT en remplacement complet, snackbar « Brouillon enregistré »).
- Tour validé avec des matchs à jouer : lecture seule + lien `/admin/matchs?tour=<tour>` (même règle que F-26).
- Phrase des barrages (maquette `13b43ad8`, fusionnée) : « Les {count} premiers de poule ne sont pas tirés : ils attendent {round}. » (singulier « Le premier de poule … il attend … »), `{count}` = premiers de poule du vivier, `{round}` = tour d'après déduit de `premiers + non-premiers / 2` (`ROUND_KIND_BY_POOL_SIZE`) ; rien n'est affiché si cette taille n'est pas 2, 4, 8 ou 16 (pas de contrôle de puissance de 2, décision c9790abd).
- Stepper des tours : construit avec les seuls endpoints existants (détail d'édition `rounds` et `pools`, puis `KNOCKOUT_ROUND_ORDER`).
- Tour par défaut : premier tour hors barrages. Barrages : nombre d'affiches = non-premiers / 2, ce qui découle du contrat (`docs/api/round-draw.md` l.67 : `DRAW_INCOMPLETE` si un joueur du vivier n'est pas tiré « sauf barrages, où seuls les barragistes le sont » ; premiers de poule refusés en barrages, `DRAW_INCONSISTENT`, RG14) ; la règle des barrages elle-même reste non calculée (decisions.md l.425). Nombre de barragistes impair : barrages non proposés (`allowedRoundKinds` de l'aperçu, non recalculé côté front).
- Contournements Origam : `aria-label` explicite sur les étapes cliquables du stepper (axe `label-content-name-mismatch`) ; bouton désactivé sans couleur ni élévation inline (sinon la règle centrale `.origam-btn--disabled` est écrasée) ; bordure de l'affiche en cours via la prop `border-color` (la variable CSS est écrasée par le style inline) ; label du select sur une ligne + opacité désactivée 0,75 (contraste axe du second select désactivé).
- Dialogues : pas de zone visuelle (F-30), `ConfirmDialog` en apparence MOCKUP comme F-24.
