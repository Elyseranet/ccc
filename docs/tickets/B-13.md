## Règles

- RG14 : avec barrages, les premiers de poule vont directement en huitièmes, puis sont mélangés avec les vainqueurs des barrages pour le tirage des huitièmes. **La composition des barrages** (qui affronte qui, combien de barragistes) n'est pas décrite au-delà : **Je ne sais pas**. Elle est fournie par le tirage, donc par la main innocente, et non calculée.
- Le nombre de qualifiés doit être une puissance de 2 pour le tour suivant. La spec ne le dit pas explicitement, mais toutes les éditions observées enchaînent 8 → 4 → 2 → 1 ou 16 → 8 → … Le contrôle est **proposé**, à valider en revue.
- `PARTICIPATION_STATUS` et `FINAL_STAGE` sont mis à jour à chaque validation de match de phase finale.

## Critères d'acceptation

- [ ] Tests unitaires : sélection « *n* premiers + *m* meilleurs *n*+1èmes » sur des poules de tailles inégales, par ratio de victoires, puis cap's average par match (A10).
- [ ] Tests d'API : un tirage de tour avant la fin du tour précédent renvoie 409 ; une double validation ne crée aucun match en plus.
- [ ] Tests d'API (barrages, scénario 2024) : les premiers de poule ne jouent pas les barrages, mais figurent dans le vivier des huitièmes.
- [ ] Tests d'API : égalité à trois → départage à trois côtés créé avec `target_score = 3` ; 3-1-0 validé ; le vainqueur prend la place qualificative, les deux perdants restent ex aequo (R-2).
- [ ] Tests d'API : égalité à quatre → un seul départage à 4 côtés, `target_score = 3` (R-1).
- [ ] R-7 (décision utilisateur 2026-10-20) : quand un départage doit pourvoir **plusieurs places**, le gagnant prend la première, puis **les perdants rejouent** entre eux (match à N−1 côtés, ou 1v1 à 5 quand il en reste deux) jusqu'à ce que toutes les places soient pourvues. Test : 4 joueurs à égalité pour 2 places → départage à 4 côtés, puis départage à 3 côtés entre les perdants ; les 2 qualifiés sont bien les deux gagnants successifs.
- [ ] `POST /editions/{id}/departages` crée le départage suivant à partir des perdants du précédent, tant que des places restent à pourvoir (R-7).
- [ ] Le tirage de tour enregistre les affiches tirées physiquement (A1) ; le tour avant les huitièmes est libellé « Barrages » (A9).
- [ ] Un match `TIEBREAK` n'apparaît pas dans les statistiques V/D (B-03).
