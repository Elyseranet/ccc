Ce que la clôture fait

  • Les points de chaque participation sont figés : barème × N / 50, N = nombre de participants (RG1, RG2).
  • L’édition passe en lecture seule partout : participants, tirages, scores, qualification.
  • Les classements ACP et All Time intègrent l’édition.
  • Un changement de barème ultérieur ne réécrit pas le palmarès.
