Règles reprises du ticket B-13 et de decisions.md : 2 joueurs = 1v1 à 5 (décision 2026-10-10) ; 3 joueurs ou plus = un seul match à N côtés, premier à 3 (A11, R-1), la mini-poule (confrontation directe) passe avant en poule (R-6) ; les perdants d'un départage à 3 restent ex aequo (R-2) ; si le départage doit pourvoir plusieurs places, le gagnant prend la première puis les perdants rejouent (R-7) jusqu'à ce que toutes les places soient pourvues : l'écran propose alors « Créer le départage suivant » avec « Places restantes : 1 ». Un match de départage est exclu des statistiques.

3. Paramètres de qualification

Aperçu : N qualifiés (n × nombre de poules + m)

Paramètres exactement ceux de l'API : { topPerPool: n, bestNextCount: m, withPlayoff: boolean } (RG18). Exemple de la spec (RG18) : à 70 joueurs, « 3 premiers + 2 meilleurs quatrièmes avec barrages » ou « 4 premiers + 8 meilleurs cinquièmes ». Aucun contrôle « puissance de 2 » à la qualification (décision utilisateur, c9790abd) : le nombre de qualifiés n'est pas refusé pour cette raison. Comment les tours s'enchaînent quand le nombre n'est pas une puissance de 2 : Je ne sais pas (la spec ne décrit que 8 → 4 → 2 → 1 et 16 → 8 → …). CORRECTION (back-lead, contrat B-13) : withPlayoff ne change pas la liste des qualifiés, seulement le type du premier tour ; l'aperçu « N qualifiés » est donc identique avec ou sans barrages, et l'écran ajoute « Premier tour à tirer : Barrages » quand la case est cochée.
origam-form, origam-text-field (inputmode numérique, pas origam-number-field : cf. decisions.md F-13), origam-switch pour les barrages.

Arrêter la liste des qualifiés ?

N joueurs seront qualifiés pour la phase finale. L'édition passe à l'état « Qualifiés validés ». La correction d'un score de poule ne sera plus possible (décision B-12, R-3). Cette action est définitive : il n'est pas possible de revenir en arrière.

Conséquence réelle (B-13) : l'édition passe à QUALIFIED dans la même transaction ; après cela, POST /matchs/{id}/correction sur un match de poule renvoie 409 NEXT_ROUND_ENGAGED. Le dialogue le dit. Aucun retour arrière (décision utilisateur, c9790abd) : le dialogue le dit en toutes lettres. Focus initial du dialogue sur « Annuler ». Bouton inactif pendant l'envoi (idempotence).
origam-dialog, origam-stepper (lecture seule) pour l'avancement, origam-snackbar « Liste des qualifiés arrêtée ».

États

LISTE ARRÊTÉE (lecture seule)

Liste arrêtée par l'administrateur le 00/00 à 00:00 : n premiers = 3, m meilleurs = 2, sans barrages. Prochaine étape : tirage du tour.

VERSION PÉRIMÉE (412) / VERSION ABSENTE (428)

Les données de l'édition ont changé depuis votre dernière lecture. Rechargez pour voir l'état actuel avant d'arrêter la liste.

CONFLIT (409) · ÉGALITÉ NON JOUÉE

La liste ne peut pas être arrêtée : une égalité reste à départager.

ÉDITION ARCHIVÉE / CLÔTURÉE

Édition en lecture seule.

CHARGEMENT / ERREUR RÉSEAU

La liste n'a pas pu être confirmée. Vérifiez l'état de l'édition avant de réessayer.
