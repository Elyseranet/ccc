Clôture · Édition 2026

Dernière étape du centre de contrôle : clôturer l'édition une fois la finale validée.

Avant de clôturer

  • Finale validée oui
  • Tous les matchs de l'édition validés oui
  • Vainqueur : Joueur A · Finaliste : Joueur B
  • Participants : N
Précondition (B-14) : 409 si la finale n'est pas validée. Si elle n'est pas remplie, la liste dit laquelle est en échec et le bouton « Clôturer » est inactif avec la raison en texte.

Ce que la clôture fait

  • Les points de chaque participation sont figés : points = barème × N / 50, où N est le nombre de participants (RG1, RG2). Exemple de la spec : 36 participants, le champion obtient 18 × 36 / 50 = 12,96 points.
  • L'édition passe en lecture seule partout : participants, tirages, scores, qualification. Toute écriture est refusée (409).
  • Les classements ACP et All Time intègrent l'édition.
  • Un changement de barème ultérieur ne réécrit pas le palmarès.

Confirmer la clôture

Clôturer l'édition 2026 ?

Les points seront figés et l'édition passera en lecture seule. Cette action est définitive : il n'est pas possible de revenir en arrière, l'édition ne pourra pas être rouverte.

« Confirmation explicite » (ticket F-26) : le bouton définitif reste inactif tant que le code de l'édition n'est pas saisi (action unique par an, irréversible dans l'API : B-14 ne définit aucune réouverture ; la spec dit seulement « Après la finale, l'édition est clôturée »). Aucun retour arrière (décision utilisateur, c9790abd). Focus initial sur le champ ; Échap annule ; bouton inactif pendant l'envoi ; clôturer une édition déjà clôturée renvoie 200 sans recalcul (idempotent), l'écran ne montre alors pas d'erreur.
origam-dialog + champ de confirmation (origam-confirm-wrapper : rôle à vérifier avant usage, sinon origam-text-field + comparaison côté écran).

États

FINALE NON VALIDÉE (409)

La clôture n'est possible qu'après validation de la finale. Aller aux scores

CLÔTURÉE (lecture seule partout)

Édition clôturée le 00/00 à 00:00 par l'administrateur. Points figés. Voir le palmarès

SUCCÈS

Édition 2026 clôturée. Les classements ont été mis à jour.

VERSION PÉRIMÉE (412) / ERREUR RÉSEAU

La clôture n'a pas pu être confirmée. Vérifiez l'état de l'édition avant de réessayer : elle est peut-être déjà clôturée.
